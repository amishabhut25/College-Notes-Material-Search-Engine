# College Notes & Material Search Engine

Web version of the college study-material project.

## Features
- Display all materials
- Add material
- Search by ID
- Search by subject
- Keyword search and autocomplete
- Sort by title
- Sort by subject
- Delete material
- Search history
- Statistics

## Run
Open `index.html` in a web browser.

## Deployment
This project is a static web application and can be deployed on Vercel.
