COLLEGE NOTES & MATERIAL SEARCH ENGINE - GUI VERSION

This project is a Java Swing GUI project using:
- Linked List
- Hashing (HashMap)
- Trie
- Stack
- Sorting

HOW TO RUN
1. Open PowerShell in this folder.
2. Compile:
   javac CollegeNotesSearchEngine.java
3. Run:
   java CollegeNotesSearchEngine

The application opens a graphical window.

GUI FEATURES
1. Display All Materials
2. Add Material
3. Search by Material ID using Hashing
4. Search by Subject using Hashing
5. Search / Autocomplete using Trie
6. Sort by Title
7. Sort by Subject
8. Delete Material
9. Search History using Stack
10. Statistics

No Java extension in VS Code is required. JDK is enough to compile and run from PowerShell.
